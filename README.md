# Accessible Email Design

A repository for guidance on creating accessible email content for newsletters, individual communications, and organisational messages.

## Overview

This project contains a source guide for accessible email design and an accompanying agent policy that describes how automated systems should generate, validate, repair, and release email content while preserving accessibility requirements.

The goal is to ensure that email content remains readable, understandable, and usable for people with permanent, temporary, and situational accessibility needs.

## Repository contents

- `Email_Accessibility.md` — the main guidance document covering accessible email design principles and best practices.
- `AGENTS.md` — operational rules for automated agents that generate, test, and repair email content against the source guidance.
- `LICENSE` — repository licensing terms.

## Key accessibility principles covered

The guidance in this repository addresses:

- logical reading order
- semantic heading structure
- minimum readable text size
- strong colour contrast
- meaningful alternative text for images
- descriptive link text
- clean HTML structure
- responsive layout
- text-only alternatives and MIME parity
- left-aligned prose with uneven right edges
- consistent, simple, and concise content design

## Intended use

This repository is intended for:

- designers creating accessible email layouts
- developers generating email templates
- automation systems validating accessibility checks
- teams preparing newsletters or transactional mailings

## Notes

This repository treats the source guide as the authoritative requirement set. The agent policy does not replace the guide or relax its requirements; it operationalises how to test, repair, and release email content responsibly.
